
# Counter App PRD

## Product Overview
A minimal single-page React application that displays a counter with increment and decrement buttons. Users can adjust the number up or down with button clicks.

## Goals
- Demonstrate a working React counter component
- Show basic state management with React hooks
- Provide a simple, functional demo app

## Core Features
- **Number Display**: Shows the current counter value prominently
- **Increment Button**: Increases the counter by 1
- **Decrement Button**: Decreases the counter by 1

## User Experience
The user sees a clean page with a number in the center and two buttons below it. Clicking the increment button adds 1 to the counter, clicking decrement subtracts 1. The counter updates immediately.

## Technical Scope
- Single React component
- State managed with React hooks
- No backend or external dependencies
- Deployable as static files

## Success Metrics
- Counter displays and updates correctly
- Both buttons work without errors
- App loads and renders immediately
